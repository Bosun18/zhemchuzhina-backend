# Жемчужина — Бэкенд

API-сервер для сайта гостевого дома «Жемчужина» (Абхазия, Пицунда).
Построен на Laravel 13 + Filament 5 + MySQL.

## Документация проекта

- [API_FRONTEND.md](API_FRONTEND.md) — документация REST API для клиентского приложения (фронтенд)
- [API_ADMIN.md](API_ADMIN.md) — документация REST API для персонала (управление бронированиями)
- [TEST_CLEANUP.md](TEST_CLEANUP.md) — список тестовых данных и файлов, которые нужно удалить перед продакшеном

## Стек

- PHP 8.5
- Laravel 13
- Filament 5 (админ-панель)
- MySQL 8
- Laravel Sanctum (аутентификация)
- Spatie Laravel Permission (роли и права)
- Spatie Laravel Activitylog (журнал действий)

## Функционал

### Публичный API
- Список номеров и их доступность по датам
- Новости и акции
- Дополнительные услуги
- Галерея
- Отзывы
- Приём ошибок фронтенда для логирования (`POST /api/log-error`, см. [API_FRONTEND.md](API_FRONTEND.md)) — записываются в отдельный канал/файл `storage/logs/frontend.log`

### API для авторизованных пользователей
- Регистрация и вход (токены Sanctum)
- Онлайн-бронирование с выбором номера и дат
- Личный кабинет (история броней)
- Написание отзывов (только после подтверждённого бронирования)
- Автоматический отзыв токена при бездействии дольше 30 минут (запрос вернёт `401`)
- Колокольчик уведомлений: список своих уведомлений, счётчик непрочитанных и отметка о прочтении (см. [API_FRONTEND.md](API_FRONTEND.md))

### Уведомления

Каждое событие шлёт **и письмо, и всплывающее уведомление (колокольчик)**. Сценарии и получатели:

| Событие | Получатели |
|---|---|
| Гость зарегистрировался | гость + администратор |
| Гость создал бронирование/отзыв | администратор |
| Бронирование подтверждено / отзыв одобрен | гость |
| Бронирование/отзыв отклонены сотрудником | гость + директор |
| Бронирование/отзыв > суток ждут обработки | директор |
| Гость сам отменил бронирование | гость + администратор + директор |

- **Email**: гостю — на почту из профиля; администратору по событиям регистрации/брони/отзыва — на адреса со страницы «Настройки уведомлений» в админ-панели; директору/администратору при отмене — на их почту.
- **Колокольчик (database notifications)**: те же события со счётчиком непрочитанных — в Filament-панели (опрос раз в 30 секунд) и доступны фронтенду через REST API.
- Логика смены статуса централизована в observer'ах (`BookingObserver`/`ReviewObserver`) и срабатывает одинаково для API, действий и формы админ-панели.

### Админ-панель (Filament)
Доступна по адресу `/admin`. Роли: администратор, директор, разработчик.
- Управление номерами и типами номеров
- Подтверждение и отклонение бронирований (с email- и всплывающим уведомлением гостя и директора)
- Сезонные цены
- Модерация отзывов (одобрение с комментарием для гостя или отклонение с email- и всплывающим уведомлением гостя и директора)
- Автоматическое уведомление директора (по почте и всплывающим уведомлением), если бронирование или отзыв остаётся в статусе «ожидает» больше суток
- Настройки уведомлений — адреса администраторов для писем о новых регистрациях, бронированиях и отзывах
- Колокольчик уведомлений в шапке панели
- Новости и акции
- Дополнительные услуги
- Галерея
- Управление пользователями (с заметками)
- Журнал активности (admin / user / system)

### Роли
| Роль | Описание |
|------|----------|
| guest | Гость — только фронтенд |
| admin | Администратор — бронирования и отзывы |
| director | Директор — полный доступ к контенту |
| developer | Разработчик — полный доступ включая пользователей |

## Установка

### Требования
- PHP 8.3+
- Composer
- MySQL 8+
- Node.js (для сборки Filament-ассетов)

### Шаги

1. Клонировать репозиторий:
```bash
git clone git@github.com:Bosun18/zhemchuzhina-backend.git
cd zhemchuzhina-backend
```

2. Установить зависимости:
```bash
composer install
```

3. Скопировать и настроить .env:
```bash
cp .env.example .env
php artisan key:generate
```

4. Заполнить .env — подключение к БД:
DB_DATABASE=zhemchuzhina
DB_USERNAME=root
DB_PASSWORD=ваш_пароль

5. Создать БД и запустить миграции:
```bash
mysql -u root -p -e "CREATE DATABASE zhemchuzhina;"
php artisan migrate
```

6. Создать администратора:
```bash
php artisan make:filament-user
```

7. Назначить роль разработчика:
```bash
php artisan tinker
$user = \App\Models\User::where('email', 'ваш@email.com')->first();
$user->assignRole('developer');
exit
```

8. Запустить сервер:
```bash
php artisan serve
```

Админ-панель откроется по адресу: http://localhost:8000/admin

## Планировщик задач

Проект использует встроенный планировщик Laravel (`routes/console.php`). На сервере нужно добавить в crontab единственную запись:

```bash
* * * * * cd /путь/к/проекту && php artisan schedule:run >> /dev/null 2>&1
```

Локально для разработки можно запустить:
```bash
php artisan schedule:work
```

Сейчас по расписанию выполняется:
- `app:notify-directors-about-overdue-pending` — ежедневно в 12:00, уведомляет директора по почте о бронированиях и отзывах, которые более суток находятся в статусе «ожидает»

## Тестовые данные

Для заполнения БД тестовыми данными (только для разработки):

```bash
php artisan migrate:fresh --seed
```
